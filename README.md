# Card_Trick

link:-


This is an interactive web-based magic trick where the user selects a card mentally, and the system correctly guesses it after three rounds.

The project is built using pure HTML, CSS, and JavaScript, making it lightweight and fully browser-based (no installation required).



🎩 Interactive 21 Card Magic Trick built with HTML, CSS, and JavaScript. 
Guesses the user’s card in 3 steps using a classic algorithm.



🎴 Displays 21 shuffled cards

🔄 3-step selection process

🎯 Accurate card prediction

📱 Responsive design

⚡ Runs completely in browser


Logic-
{Cards are divided into 3 piles
User selects which pile their card is in
After 3 rounds, the selected card always ends up in the middle position}
